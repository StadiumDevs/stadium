## 2. How each column was decided

Counts are **use in the project's own code or dependency files** (`.rs .ts .tsx .js .mjs .py .go .toml .json .html .sh .yml`, `package.json`, `Cargo.toml`, `requirements.txt`, `pyproject.toml`, `go.mod`). Excluded from the search: `node_modules`, build output, lockfiles, minified bundles, `docs/`, `evidence/`, and the shared template files most teams copied from the event (`AGENTS.md`, `AGENTS.txt`, `CLAUDE.md`, `*llms*.txt`, `docs/briefs/`). Those templates name Noir Wallet, Nym, WebZjs, Zallet, zkool and FROST, so a raw text search over-counts badly (for example 22 repos mention Noir Wallet; 11 use it).

Every Noir Wallet, Nym and WebZjs hit was then read in context by hand.

| Column | Counts as Y when the code… |
|---|---|
| Noir Wallet | imports `@noir-wallet/sdk` or calls the injected `window.noirwallet` provider (or bundles the SDK) |
| Nym | see the five statuses below |
| WebZjs | see the four statuses below |
| zcash-devtool | runs or wraps the `zcash-devtool` CLI |
| zkool | talks to `zkool` / `zkool_graphql` |
| zingo-cli | runs or wraps `zingo-cli` / zingolib |
| librustzcash | depends on `zcash_client_backend`, `zcash_primitives`, `zcash_keys`, `zcash_client_sqlite`, `zcash_protocol` or `zcash_address` |
| Zallet | calls a Zallet wallet |
| PCZT | builds or signs Partially Created Zcash Transactions |
| FROST | Zcash threshold signing (RedPallas FROST / frost-zcash-demo / zkool FROST DKG). Zool's generic `frost-ed25519` is not counted |
| Halo2 | its own Halo2 proving (Vouch and Z-Solvency, both via Valar `voting-circuits`) |
| NEAR Intents | calls the NEAR Intents / 1Click API |
| MCP | ships or calls an MCP server |
| LLM API | calls an LLM provider (Anthropic, OpenAI, Gemini, local models) |
| x402 | uses x402 payments |
| Bitrefill | calls a Bitrefill surface (MCP, REST, CLI, x402) |

**Nym statuses**
- *Built in*: the project routes its own traffic over Nym (crate, `nym-socks5-client`, or `@nymproject/mix-fetch`).
- *Through zingo-cli*: uses zingo-cli's default build, which sends over the Nym mixnet.
- *Optional proxy setting*: a SOCKS setting that can point at a Nym proxy; off by default.
- *Turned off in zingo-cli build*: built zingo-cli with `nakednet-test-mode` / without Nym to get a working demo.
- *Not used*.
"Route traffic over Nym" in the headline = Built in + Through zingo-cli.

**WebZjs statuses**: *Used (patched build)*, *Flags it as broken* (lint rules or facts that warn agents off it), *Considered, not used* (repo says they evaluated it and chose another tool), *Not used*.

**ZIPs cited**: ZIP numbers referenced in the project's own code, README or docs (template files excluded), including links to `zips.z.cash/zip-NNNN`.

**Language**: the language with the most source files; "+ Rust" when Rust is at least 15% of source files.

## 10. Findings (text for the section)

1. **Payments UX ZIPs dominate.** ZIP 321 (payment request URIs, 26 projects), ZIP 317 (fees, 25) and ZIP 316 (unified addresses, 13) are the working set. Memos are near universal in code even though only 7 projects cite ZIP 302; teams use them as order IDs, receipts and agent commands.
2. **Selective disclosure is the biggest unmet need.** Vouch, Ghost Layer and Zeno Wallet cite ZIP 311 (draft). Zeno reports the pinned crates don't implement it. Vouch and Z-Solvency reuse Valar's voting circuits to prove "at least X ZEC" without a viewing key.
3. **Agent custody pulls in FROST and PCZT.** Ironclad (ZIP 312 + ZIP 374 + ZIP 2005), Zealed and Pactora run FROST; seven projects build PCZTs. Spending limits enforced in code outside the model are the common pattern across agent projects.
4. **Ironwood and NU7 knowledge is scattered.** Teams cite ZIPs 258, 259, 229, 318, 326, 2003, 2005 and 2009 to pin heights and formats. Zec Start's feedback asks for one "what is Ironwood" page; both zcash-now entries exist to keep agents current.
5. **Missing primitives show at the edges.** zkLane needs relative timelocks (ZIPs 68/112) to close channels on chain; Finity and Mirage work around TEX addresses (ZIP 320); zshagun points to ZIP 324 for payment links.
6. **Nym is real but fragile.** Seven projects built it in. zingo-cli's Nym-by-default build made four teams turn it off to ship a demo, and three teams list it as friction in their feedback.
7. **WebZjs is effectively unavailable.** One project patched it from source; several evaluated it and moved to zcash-devtool, zkool or Noir Wallet.
8. **CLIs beat SDKs on day one.** zcash-devtool (15) and zkool (10) are the most-used ways to reach Zcash; Munim writes that zcash-devtool "built and synced the first time" where SDKs did not.
9. **Upstream contributions are few but concrete.** Four teams filed 7 PRs/issues during the hack (zcash-devtool memo walkthrough PR #271 and memo-app issue #272, Bitrefill MCP issues, a frost-zec policy co-signer request). Three more drafted upstream issues or patches in their repos without filing them.
